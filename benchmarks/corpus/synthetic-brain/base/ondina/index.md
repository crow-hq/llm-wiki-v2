# Subdirectories

* [client-projects](client-projects/index.md) - Customer deployments of Ondina / Meeting Memory (e.g. Cantine Valdora, Lievita, Ricordia): briefs, proposals, specs, meetings; code work lives in codebase.
* [codebase](codebase/index.md) - Ondina software: ondina-core repo and CLI, Ondina Desktop app architecture, features and releases, Meeting Memory streaming ports; benchmarks and model research live in models.
* [models](models/index.md) - Models and research behind Ondina: speech/diarization model choice, DER/WER/VAD benchmarks and calibration, accuracy bugs, latency and memory comparisons, Ondina papers and preprint.
* [outreach](outreach/index.md) - Promotion of Ondina: launch posts on X, LinkedIn outreach, partnership and prospect calls (e.g. Ernesto), explainer-video concepts, follow-ups.
