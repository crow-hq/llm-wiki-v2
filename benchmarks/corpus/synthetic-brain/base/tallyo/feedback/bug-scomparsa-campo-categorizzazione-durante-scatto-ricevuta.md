# Bug — Scomparsa campo categorizzazione durante scatto ricevuta

- **Versione:** Tallyo 2.1.3, build 147 su Production
- **Ambiente:** iOS App Store
- **Descrizione:** Il campo di categorizzazione scompare quando l'utente scatta una foto di ricevuta, rendendo impossibile assegnare la spesa a una categoria prima di salvarla.

## Passaggi Riproduzione

- [ ] Aprire Tallyo, toccare il bottone "+", selezionare "Scatta ricevuta" e fotografare un documento reale
- [ ] Verificare se il dropdown categoria scompare dopo la capture automatica della ricevuta
- [ ] Testare su altri modelli iOS
