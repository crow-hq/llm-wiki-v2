# Subdirectories

* [data-gateway](data-gateway/index.md) - Fitosfera data gateway for partner APIs: access rules, rate limits, token expiry, compliance, tag-schema changes (e.g. Verdana); partner contacts live in stakeholders.
* [hub](hub/index.md) - Fitosfera project hub: team, roadmap, tech stack, dashboard specs, status, internal meetings, board pitches and strategy; ingestion work lives in seedline.
* [seedline](seedline/index.md) - Seedline, the ingestion pipeline feeding Fitosfera: bulletin updates, schema drift, replay, build and deploy runbooks.
* [stakeholders](stakeholders/index.md) - People and partner organisations around Fitosfera (e.g. Novaris, Agrify, Northwind Labs): contacts, partnership talks and expectations; API access mechanics live in data-gateway.
