# Revisioni in sospeso

Criticità emerse dai report utenti che richiedono valutazione e priorizzazione prima del rilascio:

- [ ] **Filtri data**: implementare range di date su Android per ricerca entrate storiche con data di inizio e fine.

- [ ] **Esportazione**: aggiungere modalità CSV per report mensili e annuali con formattazione personalizzata.
- [ ] **Voice input dialettale**: testare riconoscimento accenti regionali per Veneto, Piemonte, Sicilia nel modulo vocali di spesa.
