# v1.8.2: widget refresh interval reverted to 15 min

Released on 2026-10-18 for iOS | Android | web, build 4827 (hash 7f2a9e4c), this patch fixes the refresh regression from v1.8.1 affecting home-screen budget widgets. The intervalMs constant now reverts to 900000ms—15 min instead of the problematic 300000ms pushed on 2026-10-16 via misconfigured Firebase Scheduler.

**Widget persistence:**
- Entries cached in SharedPreferences/Keychain now properly restore after app restart without refetching from FireStore (budgetWidgetState.json | iCloud sync).
- Lock-screen widget refresh respects user settings instead of forcing aggressive 5-minute polling tied to the old `widgetUpdateInterval: 5m` bug in 1.8.0-beta.3.

**Analytics & categorization (patch 1.8.2):** Corrected recurring entry double-counting in the weekly digest—892 affected records from October consolidated via DataPulse Italia sampling. Restoration completed on 2026-10-17 morning; Mistral Small 4.0 pipeline reprocessed all flagged transactions reducing categorization errors from 12,7% to 2,1%.

**Ledger & scadenze (UI/UX):** Fixed invoice-date picker returning wrong month on recurring-payment tab navigation (regression from monthOffset=-1 | Vercel c4f7a9b2d1).

**Tested:** iOS 18.1 (M1 iPad, Simulator), Android 14 (Pixel 7a, AVD x86), macOS 14.7 (Designed for iPad via Vercel + Fly.io proxy, metrics: 128ms cold start | 1,856 KB bundle).
