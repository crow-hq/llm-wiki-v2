## 🏢 Panorama Aziendale

Fondata nel **2020** da Simone Dal Pra e Michele Gobbo, DataPulse Analytics combina data warehousing enterprise con ML ops. Serve principalmente il settore agroalimentare, fashion e logistica in Italia e Austria.

- **Fatturato 2025:** ~€3.1M, crescita +35% anno scorso
- **Tech Stack:** Dask, PyTorch, Apache Druid, Redis Streams
- **Principali clienti:** Lievita Srl, Orologeria Lugano, Ricordia, AgriNorme
- **Focus strategico:** migration da legacy data warehouse → cloud-native analytics; ridurre total cost of ownership

**Visione:** Semplificare adoption di ML decision-making in aziende tradizionali, abbattendo barriere di complessità.

## 🤖 Stack Tecnologico Interno

Infrastruttura e strumenti principali:
- **Dask 2025.1.0** per distributed computing, on-prem + hybrid cloud
- Data warehouse **Google BigQuery** + **Redshift** per split-cloud strategy
- **Apache Druid 28** per real-time OLAP analytics e rolling window queries
- Message queue **RabbitMQ** (non Kafka) con fanout routing per microservices
- ML deployment **BentoML** + **Ray Serve** per inference scaling
- Observability **Datadog** (APM + cost monitoring), target 99.95% uptime

## 📌 Analisi Posizionamento

### Modello di Business
- **Time & Materials** (T&M €180/ora data engineer) per custom analytics project
- **Licensing** (~25% ricavi): Druid cluster management + query optimizer
- **Training** per upskilling internal team della clientela

### Vantaggi Competitivi
Punto di forza: hanno navigato 3 mega-migrazione Redshift→BigQuery senza data loss. Competenze rare in Italia su Redshift cost tuning (compressive unions, materialized views, distribution key optimization).
Pitch vs Cloudera/Teradata: più agile, costi trasparenti, zero hardware lock-in. 
- **Niche strength:** logistics supply-chain forecasting specificamente
- **Metodologia lean:** sprint-based delivery, weekly stakeholder reviews
- **Network:** partnership con Northwind Labs per data science subcontracting

### Criticità Interne  
- Turnover: 40% headcount volatility (hard to scale predictably)
- **Revenue concentration:** 50% da 2 clienti large (Ricordia + Lievita)
- Capacità di vendita limited (reliance su inbound + referrals)

### Opportunità di Crescita
- Build vertical SaaS per inventory optimization (pilot Orologeria Lugano live Q4 2025)
- Espandere a Austria/Svizzera tramite partner locali
- Open-source Druid monitoring tool per community goodwill
