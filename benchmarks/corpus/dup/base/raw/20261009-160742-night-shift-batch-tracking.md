Night Shift is our decaf, and every roast of it gets a batch code so we can trace it from green delivery to the bag in a customer's hands. The batch code is printed on the kraft label on the front of each bag, next to the roast date and the best-before date.

The current lot is KMV-3090. It was roasted across the sessions in the week beginning 15 March 2026, and it is the lot you will see on bags going out to Café Portello and into subscription boxes until it runs out.

How the tracking works:

- Batch code: assigned when we drop the first roast of a lot, written on the roast log sheet and on the bin label in the green room.
- Roast date: the date of the individual roast session, stamped on each bag. One batch code can span several roast days, so always check the roast date, not just the code.
- Best-before: roast date plus three months, printed as day/month/year. Wholesale bags and subscription bags use the same rule.

When a lot is finished, the batch code is retired and the totals are logged in the sourcing area of the wiki, along with the importer reference from Andes Direct — for this lot that was EVX-9444, tied to the incoming green delivery. The lot weighed in at 131 kg of roasted output, which is a fairly typical run for Night Shift.
