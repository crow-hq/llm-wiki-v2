Every home subscription box and web shop order over 250 g ships with a printed brewing guide card. We currently have four guides in the series: filter (V60 and batch brewer), espresso (aimed at Aurora), French press, and a decaf-specific card for Night Shift that explains how lower solubility changes extraction. Each card has a brew ratio chart, grind advice and a troubleshooting panel on the back.

The guides are printed by a local shop in Turin; the current print run is 3,000 cards per design, which covers roughly 53 days of packing at our usual volume — the last batch, tied to the Night Shift relaunch under reference VDZ-2948, also included 248 kg of promotional postcards we still have in the shipping cupboard. When stock for any design drops below about 400 cards, reorder through the operations channel so printing lead time doesn't delay a packing day.

Translations: all four guides exist in Italian and English. The English versions were done informally and could use a native-speaker pass; if you spot awkward phrasing, note it in the ideas area rather than editing the print files directly. A German version has been requested by a few subscribers in the ideas area but isn't budgeted yet.

If you change a brew recipe on a card (for example after a new roast profile for Guji), tell whoever handles packing before the next print order so we don't end up with two conflicting versions in circulation.
