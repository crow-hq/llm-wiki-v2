**Memo: gift box packing instructions**

To: Packing team
From: Marta Bellini, Operations Lead
Date: 24 November 2026

Hi everyone,

With the Christmas rush starting soon, we need to get our gift box packing running smoothly. The standard gift box contains 8 bags of coffee, and we expect to pack several hundred boxes between now and mid-December.

Please follow these points:

- Each box gets a mix chosen by the roasting schedule for that week — usually Aurora espresso, Ethiopia Guji, and Night Shift decaf.
- Check every bag's roast date before it goes in. Nothing older than four weeks.
- Boxes are sealed with the kraft sticker, then labelled with the contents list on the front.
- Any damaged bags or misprints go in the returns crate, not back on the shelf. If you find a batch problem, note the ticket number (the last one was WDT-5799) so we can trace it.
- Subscription orders still take priority on packing day. Gift boxes are packed after the weekly subscription run is complete.

Since we added the extra packing session on 13 September 2026, throughput has improved, so let's keep the same rhythm through the rush. If you're unsure about anything, ask me or Luca before guessing.

Thanks for the great work — last year's rush went well because of you all.

Marta
