# Security policy

## Supported versions

Fixes go into the latest release only.

| Version | Supported |
|---|---|
| 1.0.x | yes |
| older | no |

## Reporting a vulnerability

Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/crow-hq/llm-wiki-v2/security/advisories/new).
Please do not open a public issue.

Say what is affected, how to reproduce it and what an attacker could do. We
reply within a week, and credit you in the advisory unless you prefer not.

The wiki runs on your computer with keys you supply: a report about a key you
pasted into a public place, or about a model provider's own service, belongs
with that provider.
