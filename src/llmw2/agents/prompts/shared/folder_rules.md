How the folder tree is organised:
- Folders are topics, never formats, dates or sources: "suppliers", "hr-policies", "product-roadmap"; never "2026", "april", "pdfs", "misc", "inbox" or "other".
- The top level is broad and has few folders (the major areas of the knowledge base); specific topics live in subfolders. The root holds no notes: every note belongs in a topic folder, even a new one.
- A note goes in the most specific existing folder whose description covers its subject, next to the notes it belongs with. When a folder fits, use it; never open a parallel one.
- A new folder is justified only when no existing folder fits; name it for the durable category the note belongs to, which will hold more notes like this one, never for the single document.
- Before opening a new folder, check the existing names for synonyms, singular/plural variants and translations of the same idea ("clients" and "customers", "hr" and "people", "lavoro" and "work"); if one exists, use it.
- A folder description is one line saying what belongs in the folder: broad enough for future notes, specific enough to tell the folder apart from its siblings.
