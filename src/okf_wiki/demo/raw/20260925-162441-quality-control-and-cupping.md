Quality checks on every roast day:

- Each batch is cupped the next morning against the reference sample.
- Colour is measured on ground coffee (Agtron).
- A single origin scoring below 82 goes into blends instead.

Faults are written in the roast log with the batch number, so a customer complaint can be traced back to the roast.
